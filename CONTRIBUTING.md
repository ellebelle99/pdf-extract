# Contributing

Thanks for wanting to improve this skill.

It is maintained by Andreas Ellegaard Andersen, who reviews every change before it goes in.


## What fits

The skill has one job: extract a PDF to raw markdown with `pymupdf4llm` and rename captioned figures.

Welcome: better caption matching, a missing edge case such as multi-line captions, clearer setup wording.

Unlikely to be accepted: formatting or cleanup of the markdown, or switching to another extractor.


## How to propose a change

1. Open an issue first for anything bigger than a typo.
2. Fork the repository and create a branch.
3. Edit `skills/pdf-extract/SKILL.md`.
4. Try the changed behavior in Claude Code.
5. Open a pull request, and say what you tried and what happened.

A skill is instructions, not code, so there is no automated test run.


## Conduct

Be respectful. Threads that are not may be closed.
